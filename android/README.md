# ICT Brain Android v2.0.0

Native Android screenshot analyzer. The active analysis path uses ML Kit Prompt API / Gemini Nano through Android AICore on supported devices. Images are analyzed on-device; the app does not embed an external AI/API credential and declares no INTERNET permission.

Workflow: select 1–4 TradingView screenshots -> label instrument/timeframe -> Find One Trade -> one LONG/SHORT plan or WAIT.

Recommended 4-chart stack: 1H NQ, 15m NQ, 5m MNQ, 1m MNQ.

The APK installs on Android 8.0+ (API 26), but on-device generative analysis requires a device where ML Kit reports Gemini Nano AVAILABLE or DOWNLOADABLE.
